# Food Delivery Website

A modern, responsive food delivery website built with HTML, CSS, and JavaScript.

## Features

- 🍔 **Dishes Page**: Browse food items categorized as Food, Drinks, and Desserts
- 🛒 **Shopping Cart**: Dynamic cart with add/remove functionality and quantity controls
- 💳 **Payment Page**: Select payment method and view order summary
- 📍 **Address Page**: Enter delivery address and contact information
- ✅ **Confirmation Page**: Order confirmation with delivery status timeline

## Getting Started

1. Open `index.html` in your web browser
2. Browse the available dishes and click "Add to Cart" to add items
3. Click the cart button to view your cart and modify quantities
4. Click "Proceed to Checkout" to start the checkout process
5. Fill in payment and delivery information
6. Confirm your order to see the delivery status

## Design

- **Color Scheme**: Green (#2d8659) and white theme
- **Responsive**: Works on desktop, tablet, and mobile devices
- **Icons**: Emoji-based iconography for visual appeal
- **Storage**: Uses localStorage to persist cart data

## Files

- `index.html` - Main dishes page
- `payment.html` - Payment information page
- `address.html` - Delivery address page
- `confirmation.html` - Order confirmation page
- `styles.css` - All styling and responsive design
- `script.js` - JavaScript for cart functionality and interactions
